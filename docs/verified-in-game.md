# Verified in game: Context

The checks show that the code compiles and that the logic tests pass. Whether a feature works in
the game is only known by trying it there. This file keeps track of what was seen working, when,
and on which build, so "it probably works" doesn't stay that way for months.

One line per session, newest first:

```
- YYYY-MM-DD HH:MM - <commit> - <game build> - <works | broken | partly> - <what you saw, and what you didn't get to>
```

`<commit>` is the last commit that was actually loaded in the game during the session. Write a line
only after seeing it in game, and say what wasn't tested as well as what was.

## Test guide: built, not yet seen in game

Same shape as Mage Kit's checklist: what to do, what you should see, the known-good control that
tells a broken feature from a wrong expectation, and how to read a wrong outcome. A confirmed row
becomes a line in the log. Grouped by **where you need to be**. One row per acceptance criterion
1-5 of the spec (`docs/specs/contextual-cooldowns.md`; the criterion is named in the row, and
criteria 1 and 3 get one row per place), plus `/context probe` in each place, the Cooldown Manager
edges, and the preset's first-login install.

In game, **`/context tests`** opens the guide: these rows one at a time, with the buttons a step
needs (Probe, Probe Ice Barrier, Probe Counterspell, List displays, Preset mage, Edit, Reset
displays, Reload UI) and As expected / Not as expected / Skip for now, plus a note box. The answer,
the note, the game build and the last button's output are saved in
`ContextDB.testGuide.results[<row id>]`, read back from SavedVariables after logout. It opens by
itself a few seconds after login while rows are left (its "At login" button turns that off). Each
row here has its entry in `TestGuideSteps.lua`, same ID, same order: the headless test fails
otherwise.

Before starting: log in on a mage. T0 is the setup every other row needs. The letters in the
probe's brackets: A = Lua read it plainly, B = an event said so, D = hidden (only the engine can
draw it), E = asked first and told it would be hidden here.
